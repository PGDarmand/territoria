# Commands

Everything below can also be done from the menus. `/country help` lists the commands in game, and you can click
them to type them.

## Players

| Command | Action |
|---|---|
| `/country` | Open the country menu |
| `/country create <name>` | Found a country |
| `/country invite <player>` · `/country kick <player>` | Invite / remove a member |
| `/country leave` · `/country disband` | Leave / delete your country |
| `/country claim` · `/country unclaim` | Claim / release the chunk you stand in |
| `/country home` | Teleport to the capital |
| `/country info [name]` · `/country list` | Country details / every country |
| `/country color <hex>` | Change the country color |
| `/country banner` | Turn the white banner in your hand into your flag |
| `/country ally <name>` · `/country enemy <name>` · `/country neutral <name>` | Relations |
| `/country war <name>` · `/country peace <name>` · `/country surrender <name>` | War |
| `/country capture` | Capture the enemy chunk you stand in |
| `/country trust <player>` · `/country untrust <player>` | Give / remove the Ally role to an outsider |
| `/country tax <amount> [role]` | Daily tax, for everyone or one role |
| `/country plot wand` | Get the plot wand |
| `/country plot create <price> <days> <name>` | Turn your selection into a plot |
| `/country plot delete <id>` | Delete a plot |
| `/country plot rent` · `/country plot leave` | Rent / leave the plot you stand in |
| `/country levelup` | Buy the next research level |
| `/country chat` · `/cc <message>` | Country chat |
| `/country sidebar` | Show / hide the country sidebar |

## Admins

Needs `territoria.admin` (operators by default). `/territoriaadmin help` lists them in game.

| Command | Action |
|---|---|
| `/territoriaadmin bypass` | Ignore claim protection until you log out |
| `/territoriaadmin logs [page]` | Moderation history |
| `/territoriaadmin claim <country>` · `/territoriaadmin unclaim` | Give / free the chunk you stand in |
| `/territoriaadmin tp <country>` | Teleport to a country |
| `/territoriaadmin setbalance <country> <amount>` | Set a bank balance |
| `/territoriaadmin setlevel <country> <level>` | Set a research level |
| `/territoriaadmin endwar <country>` | End all wars of a country |
| `/territoriaadmin delete <country>` | Delete a country |
| `/territoriaadmin reload` | Reload the config file and the server logo |
