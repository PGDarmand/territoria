# Territoria

Countries, claims, diplomacy and wars for Minecraft 1.21.1 (NeoForge), all from clean custom menus.

Found a country, claim land right on the map, organise members with custom roles, fill a shared bank, rent out
apartments, make allies and go to war.

- Minecraft **1.21.1**, **NeoForge 21.1.219+**, Java 21
- Install it on the **server and on every player's client**
